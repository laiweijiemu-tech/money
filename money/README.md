# money

## 龙头战法页面选股规则

本文整理的是 `龙头战法` 功能页面当前实际使用的选股逻辑，包含页面展示规则和后端真实生效的打分、入池、淘汰条件。

### 1. 核心思路

- 观察窗口：重点看 `9:30-10:00`，任务是确认当天最强主线和主线龙头，不做早盘盲目抄底。
- 主线优先：优先做资金流靠前、涨幅靠前的热门题材和强势行业，不做边缘题材。
- 龙头优先：优先选题材龙头、行业领涨股，以及同时出现在市场热度榜里的个股，不做后排跟风。
- 强度优先：先看涨幅、成交额、热度、题材/行业地位、公告催化，再考虑价格，不因为股价低就放宽标准。
- 共振优先：理想候选要有 `题材 + 行业 + 热度 + 公告催化 + 盘中强度 + 成交额` 中的多项共振。
- 风险回避：默认回避 `ST`、无成交额支撑、涨幅弱、没有题材共振、没有资金和关注度支撑的个股。

### 2. 候选池怎么来的

页面会先把多个来源合并成一个候选池，再统一打分和筛选：

- 市场快照：盘中涨幅和成交额靠前的股票。
- 热门题材榜：题材板块的龙头股。
- 行业资金流榜：行业领涨股。
- 热门股/人气榜：市场热度高的股票。
- 公告催化：业绩预告、财报、重大事项等正负催化信息。

### 3. 初始入池条件

股票并不是全市场无差别进入候选池，至少需要先满足以下基础条件之一：

- 来自热门题材龙头。
- 来自行业领涨股。
- 出现在市场热度榜。
- 出现在盘中市场快照中，并且满足：
  - `涨幅 >= 2%`，或
  - `成交额 >= 1 亿`。

也就是说，盘中涨幅 `>= 5%` 已经不是入池硬门槛，低位股票只要有题材/行业/热度/公告等信号，仍然可以先进入候选池参与后续筛选。

### 4. 打分规则

后端会对候选池里的每只股票累积打分，分数越高，排序越靠前。

#### 4.1 市场快照加分

- 盘中涨停或接近封板：
  - 若市场强势排名前 20，`+18`
  - 否则，`+14`
- 盘中涨幅 `>= 7%`：
  - 若市场强势排名前 20，`+12`
  - 否则，`+8`
- 若涨幅没有特别突出，但成交额 `>= 10 亿`，`+6`

#### 4.2 题材龙头加分

- 热门题材榜前 3 的龙头，`+38`
- 热门题材榜第 4-6 名的龙头，`+28`
- 其余进入热门题材榜的龙头，`+18`

#### 4.3 行业龙头加分

- 行业资金流榜前 3 的领涨股，`+24`
- 行业资金流榜第 4-6 名的领涨股，`+16`
- 其余进入行业榜的领涨股，`+10`

#### 4.4 热度加分

- 人气榜前 3，`+8`
- 人气榜前 10，`+5`
- 其余上榜，`+2`

#### 4.5 公告催化加分

- 若个股在对应交易日存在正向公告催化，会按催化类型追加正分。
- 若存在负向公告催化，也会记入负分。
- 正向催化会把 `has_catalyst` 标记为真，后续会影响是否允许低位预判入池。

#### 4.6 盘中强度加分

- 涨幅 `>= 9.5%`，`+25`
- 涨幅 `>= 7%`，`+20`
- 涨幅 `>= 5%`，`+14`
- 涨幅 `>= 3%`，`+8`
- 涨幅 `< 0`，`-8`

这里的 `涨幅 >= 5%` 是强度参考项，不再是必须满足的硬条件。

#### 4.7 成交额加分

- 成交额 `>= 15 亿`，`+14`
- 成交额 `>= 8 亿`，`+10`
- 成交额 `>= 3 亿`，`+6`

#### 4.8 风险扣分

- 名称包含 `ST`，`-40`

### 5. 真正入选候选股的条件

候选池里的股票即使分数大于 0，也不一定能最终进入页面的 `候选股` 列表，还要通过以下严格筛选。

#### 5.1 必须具备主线共振或强势直通

满足以下之一即可：

- 有题材龙头属性。
- 有行业龙头属性。
- 有公告催化。
- 或者盘中涨幅 `>= 9.7%` 且成交额活跃，视为 `强势涨停直通`。

如果以上都没有，会被淘汰，原因是：

- `没有题材/行业/公告催化共振，且未达到强势涨停直通条件`

#### 5.2 盘中强度不足时，必须有额外支撑

系统把 `涨幅 >= 5%` 视为 `强势`，但它不是绝对硬门槛。

若盘中涨幅不到 `5%`，也不是直接淘汰，只要同时满足以下补充条件仍可通过：

- 有公告催化，并且
- 还至少满足以下之一：
  - 有题材龙头属性
  - 有行业龙头属性
  - 成交额活跃
  - 有市场热度

不满足时会被淘汰，原因是：

- `盘中强度偏弱，且缺少足够的公告催化支撑`

#### 5.3 共振项数量至少 3 个

系统会统计以下 7 个共振项：

- 题材龙头
- 行业龙头
- 市场热度
- 市场快照强势记录
- 盘中涨幅是否达到强势
- 成交额是否活跃
- 公告催化

上述项目合计少于 `3` 个时，会被淘汰，原因是：

- `共振项不足`

### 6. 候选股排序规则

通过严格筛选后的股票，会按以下优先级排序：

1. 总分高的优先
2. 共振项更多的优先
3. 盘中涨幅更高的优先
4. 成交额更大的优先

页面默认展示前若干名作为最终候选。

### 7. 淘汰股是什么

页面里的 `淘汰股` 不是完全没关注价值，而是：

- 已进入候选池；
- 有一定分数；
- 但没有通过最终严格筛选。

常见淘汰原因包括：

- 没有题材/行业/公告催化共振；
- 盘中强度偏弱，且没有足够公告催化支撑；
- 共振项数量不足；
- `ST` 风险；
- 成交额不足，或仅有单一信号，没有形成主线共振。

### 8. 一句话总结

龙头战法当前不是简单用 `涨幅 >= 5%` 机械选股，而是：

- 先把 `题材龙头、行业龙头、热度股、强势股、公告催化股` 合并进候选池；
- 再用 `主线共振 + 盘中强度 + 成交额 + 公告催化` 做综合打分；
- 最后要求至少形成足够共振，才能进入最终候选名单。
